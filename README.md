# Milo English

A colorful, game-inspired English learning app for Vietnamese primary-school students (ages 6–10), built with Flutter.

The project is being bootstrapped from an empty repository. See `docs/` for setup, architecture, and Android APK build instructions.

## Target platforms
- Android (APK first)
- Windows / Ubuntu development environments

## Quick start
Flutter SDK 3.24+ and Dart 3.5+ are required. See `docs/GETTING_STARTED.md` once the initial app scaffold is added.
